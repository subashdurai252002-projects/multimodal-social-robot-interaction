# Multimodal Social Robot Interaction

A ROS 2-based research and development project investigating natural,
speech-based human-robot interaction for social robots.

## Overview

This project explores multimodal communication for social robots by
combining speech recognition, conversational AI, speech synthesis,
and audio processing.

The work is being developed as part of a Master's thesis at
Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU).

## Technologies

- Ubuntu 24.04
- ROS 2 Jazzy
- Python
- ReSpeaker Microphone Array
- Whisper Speech Recognition
- Gemini and Qwen Language Models
- Piper Text-to-Speech
- Voice Activity Detection
- Acoustic Echo Cancellation

## Project Structure

- `src/` - Final working Tasks 1–5 programs
- `models/` - Stop-command wake-word models and evaluation data
- `piper_voices/` - Piper text-to-speech voice model
- `tools/` - DTLN-AEC and supporting audio tools
- `docs/` - Tasks 1–5 technical and meeting documentation
- `results/` - Saved logs and audio evidence
- `test_audio/` - Runtime audio generated by the current programs
- `experiments/` - Development and experimental implementations
- `archive/` - Backups and legacy development environments
- `task5_final_baseline/` - Frozen Task 5 baseline and metrics

The three active entry files are:

- `src/speech_gemini_respeaker.py`
- `src/speech_qwen_respeaker.py`
- `src/barge_in_detector.py`

See `docs/PROJECT_MAP.md` for the complete directory guide and run commands.

## Current Development Status

The project currently focuses on speech interaction,
acoustic echo cancellation, interruption detection,
and performance evaluation.

Integration with the complete social robot architecture
and physical robot platforms is part of the broader
development roadmap.

## Research Context

The project investigates natural human-robot interaction
using multimodal sensing and adaptive communication.

Target platforms include Unitree and Pepper social robots.

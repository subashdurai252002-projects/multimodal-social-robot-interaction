# Experiments

These files document the development path and are not the current production entry points.

- `barge_in/`: wake-word, echo-cancellation, cascade, soft-pause and asynchronous trials.
- `speech_recognition/`: earlier transcription, VAD and ReSpeaker scripts.
- `echo_cancellation/`: offline and WebRTC AEC implementations.

The current implementation remains in the project root. Some experiments may contain hard-coded paths from the period when they were created; moving them here preserves the source but does not guarantee they can be run without path updates.
